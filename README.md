A pure-Python program (standard library only) that paints a newspaper front page summing up the world news of Saturday 21 November 2026 - Russia firing more than 400 drones and 110 missiles at Ukraine with missiles landing in Poland, the AI sell-off pushing the S&P 500 into correction, tankers hit near Hormuz, a pancreatic-cancer pill breakthrough, and more - and writes it as a 1024x1024 PNG to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
